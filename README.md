# Project 2: Data Classification Using AI

Batch: 2026 | Powered by DecodeLabs

## 📋 Overview

This project demonstrates a complete supervised learning pipeline for data classification using the Iris dataset. It implements K-Nearest Neighbors (KNN) algorithm to classify iris flowers into three species based on their measurements.

## 🎯 Project Goals

- Load and understand the Iris dataset
- Apply feature scaling (StandardScaler)
- Split data into training and testing sets
- Implement K-Nearest Neighbors classification
- Evaluate model performance using various metrics

## 📊 Dataset

**Iris Dataset**
- Samples: 150 (50 per class)
- Classes: 3 (Setosa, Versicolour, Virginica)
- Features: 4 (Sepal Length, Sepal Width, Petal Length, Petal Width)
